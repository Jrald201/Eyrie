About Eyrie

Eyrie is a simple browser extension for managing your own HTTP/HTTPS proxies. It provides a compact interface for importing, saving, switching, and enabling or disabling proxy configurations.

Features

  • Import and save multiple proxies
  • Quick proxy switching and manual selection
  • One-click proxy enable/disable
  • Proxy authentication support
  • Light and Dark interface
  • Clear browser data
  • Reset open tabs

Privacy

Eyrie stores proxy configurations and preferences locally in the browser's extension storage. Eyrie does not require an account or sign-in.
