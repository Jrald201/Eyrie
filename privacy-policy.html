ProxyNest Privacy Policy

Last updated: November 16, 2026

ProxyNest is a Chrome extension for managing user-provided HTTP/HTTPS proxy configurations.

Information Stored

ProxyNest may store the following information locally in Chrome extension storage:

  • Proxy server addresses and ports
  • Proxy usernames and passwords provided by the user
  • Selected proxy settings
  • Extension preferences such as theme selection

How Information Is Used

This information is used only to provide ProxyNest's proxy management features, including configuring proxies, switching between proxies, and authenticating with proxy servers when required.

Data Sharing

ProxyNest does not sell, rent, or share stored user information with third parties.

ProxyNest does not collect analytics, browsing history, website content, or personal information.

Data Storage

Proxy configurations and credentials are stored locally using Chrome's extension storage. ProxyNest does not operate a server that receives or stores this information.

Users are responsible for the proxy credentials they choose to save.

Browser Data

ProxyNest's optional Clear Data feature uses Chrome's browser data APIs to remove selected browser data when the user explicitly requests it. ProxyNest does not collect or store the browser data that is removed.

Reset Tabs

The optional Reset Tabs feature opens a new tab and closes the user's currently open tabs when the user activates the feature. ProxyNest does not collect or store information about those tabs.

Changes to This Policy

This privacy policy may be updated when ProxyNest's data practices change. Any updated version will be published at the same privacy-policy URL.

Contact

For questions about this privacy policy or ProxyNest, please use the support contact provided on the Chrome Web Store listing.
