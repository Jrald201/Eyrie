ProxyNest Privacy Policy

Last updated: November 19, 2026

ProxyNest is a browser extension for managing user-provided HTTP, HTTPS, SOCKS4, SOCKS5, and PAC proxy configurations.

Information Stored

ProxyNest may store the following information locally in the browser's extension storage:

  • Proxy server addresses and ports
  • Proxy usernames and passwords provided by the user
  • Proxy configuration types
  • PAC scripts and PAC URLs provided by the user
  • Selected proxy settings
  • Extension preferences such as theme selection

How Information Is Used

This information is used only to provide ProxyNest's proxy management features, including configuring proxies, switching between proxies, applying PAC configurations, and authenticating with proxy servers when required.

Data Sharing

ProxyNest does not sell, rent, or share stored user information with third parties.

ProxyNest does not collect analytics, browsing history, website content, or personal information.

Data Storage

Proxy configurations and credentials are stored locally using the browser's extension storage. ProxyNest does not operate a server that receives or stores this information.

Users are responsible for the proxy credentials they choose to save.

Backup Files

ProxyNest's Export Backup feature creates backup files locally on the user's device. Exported backups may contain proxy configurations, including proxy usernames and passwords.

Backup files are not uploaded to ProxyNest or stored on a ProxyNest server. Users are responsible for storing exported backup files securely.

PAC Configurations

ProxyNest allows users to provide PAC scripts and PAC URLs. PAC configurations can control how browser traffic is routed. Users should only use PAC scripts and PAC URLs that they trust.

ProxyNest does not host or control third-party PAC scripts or PAC URLs.

Browser Data

ProxyNest's optional Clear Data feature uses browser data APIs to remove selected browser data when the user explicitly requests it. ProxyNest does not collect or store the browser data that is removed.

Changes to This Policy

This privacy policy may be updated when ProxyNest's data practices change. Any updated version will be published at the same privacy-policy URL.

Contact

For questions about this privacy policy or ProxyNest, please use the support contact provided on the applicable browser extension store listing.
