# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Eyrie, please report it privately rather than creating a public GitHub issue.

You can report security vulnerabilities through GitHub's private vulnerability reporting feature or through the contact information available on the Eyrie website.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The affected component
- The potential impact

Please do not publicly disclose the vulnerability until it has been reviewed.

## Supported Versions

Only the latest version of Eyrie is actively supported.

## Scope

Security issues affecting Eyrie itself are within scope, including issues involving the extension's code, proxy authentication, local storage, permissions, and other extension functionality.

## Response

Security reports will be reviewed as soon as reasonably possible.

Thank you for helping keep Eyrie secure.
